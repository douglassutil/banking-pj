# Definition of Done — Intern Training Standard

A task is considered complete only when ALL items below are satisfied.

---

## Functional

- Feature works as expected
- No runtime errors
- API responds correctly

---

## Code Quality

- Code compiles
- No unused variables
- No debug logs left in code
- Clear variable names

---

## Validation

- Input validation implemented
- Error handling exists

---

## Testing

- Manual test executed
- Expected behavior confirmed

---

## Version Control

- Code committed
- Commit message follows pattern

Example:

feat: create login endpoint

---

## Important Rule

If any item is missing, the task is NOT done.

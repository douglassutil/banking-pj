# Code Review Checklist — Intern Level

Use this checklist before merging code.

---

## Readability

- Variable names are clear
- Functions are small and focused
- Code is easy to understand

---

## Structure

- Files are in the correct folders
- No duplicated code
- Logic is separated properly

---

## Validation

- Input validation exists
- Error handling implemented

---

## Logging

- No console.log left in production code

---

## Security

- Sensitive data not exposed
- Token or password not logged

---

## Testing

- Manual test executed
- Expected result confirmed

---

## Final Question

Would another developer understand this code quickly?

# Student Guide — Beginner Developer Training Program

This guide explains how to work through the training program step by step.

It is designed for intern-level developers with limited experience who want to learn how real software development works.

---

# Your Mission

Your goal is not just to write code.

Your goal is to learn how to work like a professional developer.

By the end of this program, you should be able to:

- Understand a real codebase
- Implement features step by step
- Fix problems independently
- Deploy applications to production
- Follow professional workflows

---

# How This Training Works

You will work in **Sprints**.

Each sprint contains:

- Tasks
- Steps
- Manual tests
- Completion criteria

You must complete tasks in order.

Do not skip steps.

Do not rush.

Consistency is more important than speed.

---

# Daily Routine (Very Important)

Follow this routine every day.

1 — Open the current Sprint document

2 — Read the Sprint Objective

3 — Execute one task at a time

4 — Test the feature manually

5 — Commit your code

6 — Move to the next task

---

# Rule #1 — Always Make Small Progress

You do not need to be fast.

You need to be consistent.

Even small progress every day leads to strong results.

---

# Rule #2 — Always Test Your Work

After finishing a task:

- Run the application
- Verify behavior
- Fix errors immediately

Never assume the code works.

Always confirm.

---

# Rule #3 — Commit Frequently

Make commits often.

Recommended:

- One commit per task

Example commit messages:

feat: create account form

fix: handle validation error

refactor: move logic to hook

---

# When You Get Stuck

Getting stuck is normal.

Do not panic.

Follow this process.

Step 1 — Read the error message carefully

Step 2 — Check the code you just wrote

Step 3 — Search documentation

Step 4 — Ask for help

---

# How to Ask for Help (Important)

When asking for help, always include:

- What you tried
- What happened
- Error message
- Code snippet

Bad example:

It does not work

Good example:

I tried to create an account but received a validation error.

Error message:

Invalid amount value

---

# Expected Daily Time

Recommended:

4 to 5 hours per day

If you study part-time:

2 to 3 hours per day

---

# How to Know You Are Doing Well

You are progressing correctly if:

- The application runs
- Tasks are completed
- Errors are fixed
- Code is committed
- Features work as expected

---

# Common Beginner Mistakes

Avoid these mistakes.

Skipping tasks

Copying code without understanding

Ignoring errors

Working without testing

Waiting too long to ask for help

---

# Weekly Review

At the end of each week, you should:

- Review completed tasks
- Fix remaining errors
- Clean up code
- Demonstrate working features

---

# What You Will Learn

During this training, you will learn:

Frontend development

Backend development

API communication

Authentication

Validation

Security

Deployment

CI/CD

---

# Final Goal

Your final goal is to build and deploy a real application.

Not a tutorial project.

A real system.

---

# Remember

You are not expected to know everything.

You are expected to keep learning.

Consistency beats talent.

Discipline beats motivation.

Progress beats perfection.

# Training Schedule — Beginner Developer Program

This document defines the official timeline for the intern training program based on the implemented sprints.

The goal is to provide a realistic, structured progression similar to a real internship environment.

---

# Program Duration

Recommended duration:

8 weeks

Workload:

- 4 to 5 hours per day
- 5 days per week

Alternative modes:

Full-time internship:

8 weeks

Part-time learning:

12 to 16 weeks

---

SPRINT 12 — Transactions

---

# Daily Structure (Recommended)

Daily routine:

1 — Read the sprint objective

2 — Execute tasks sequentially

3 — Perform manual tests

4 — Commit code

5 — Review checklist

---

# Weekly Review Ritual

At the end of each week:

- Review completed tasks
- Fix pending issues
- Refactor unclear code
- Ask questions
- Demonstrate working features

---

# Milestones

End of Week 2:

Working CRUD interface

End of Week 4:

Well-structured frontend architecture

End of Week 6:

Production-ready backend behavior

End of Week 8:

Fully deployed and automated system

---

# Completion Criteria

The program is considered complete when:

- All sprints executed
- Application runs locally
- Application deployed to production
- CI/CD pipeline working
- Code passes review checklist

---

# Mentor Responsibility

Mentor should:

- Review progress weekly
- Answer technical questions
- Validate Definition of Done
- Encourage consistent progress

---

# Student Responsibility

Student should:

- Follow tasks step by step
- Test every feature
- Commit frequently
- Ask questions early
- Keep code organized

---

# Expected Outcome

After completing this program, the student should be able to:

- Build a full-stack application
- Understand modern development workflow
- Deploy applications to the cloud
- Work with version control
- Follow professional engineering practices

# Setup — React Beginner Track

## Pré-requisitos

- Node.js 20+
- Docker
- Git

---

## Passo a passo

### 1. Clonar projeto

```bash
git clone https://github.com/douglassutil/banking-pj
cd banking-pj
```

### 2. Instalar dependências

```bash
npm install
```

### 3. Subir banco de dados

```bash
npm run db:up
```

### 4. Rodar backend

```bash
npm run dev:api
```

Backend disponível em:

http://localhost:3000

---

### 5. Rodar frontend

```bash
npm run dev:frontend
```

Frontend disponível em:

http://localhost:5173

---

## Verificação

- Backend rodando
- Frontend rodando
- Banco rodando

Se tudo estiver ok, você está pronto para iniciar os sprints.
